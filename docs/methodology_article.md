# 诚实第一：足球赔率量化研究的纪律与方法论

> 一份面向外界（潜在合作方 / 技术同行 / 接手工程师）的方法论白皮书。
> 核心立场：**本系统定位为「概率诊断透镜」，不是「开处方机」。** 任何盈利声称都必须先过诚实门禁，无 edge 不宣称盈利。

---

## 0. 一句话立场

我们做足球赔率量化，但**不以 ROI 论英雄**。ROI 是正的，只能说明「待解释的现象」，不代表「可交易的能力」。把度量偏差当利润，是这一行最贵的错误。

---

## 1. 校准优先，而非胜率优先

传统博彩量化把「命中率」「ROI」挂在嘴边。我们反其道而行——**主指标是校准（calibration），不是盈利**。

| 指标 | 含义 | 用途 |
|---|---|---|
| LogLoss | 概率预测的负对数似然 | 衡量概率质量（越低越好） |
| Brier Score | 概率与二值结果的均方误差 | 整体准确性 |
| ECE (Expected Calibration Error) | 预测概率与实际频率的偏离 | 校准可信度 |

为什么？因为在一个**赔率由市场集体定价的强有效环境**里，想长期稳定击败开盘价（即产生 `实际胜率 > 隐含概率 + 抽水`）极难。与其假装能赚，不如先把「我给的概率到底准不准」这件事钉死。系统若连校准都过不了，盈利更是无源之水。

**诚实结论（截至 2026-09-24 六道关）：全系统无已验证可交易边缘。** 这是我们自己跑出来的、不愿隐瞒的结论。

---

## 2. 去水（devig）必须用幂法，比例法是陷阱

赔率含抽水（overround）。要把赔率还原成「市场对真实概率的估计」，需去水。

### 2.1 比例法为什么有毒

比例法按各结果概率**比例**均摊抽水：

```
p_i = (1 / o_i) / Σ(1 / o_j)
```

真实市场的抽水分配**并非**比例均摊，而是更偏向冷门（favorite-longshot bias, FLB）。比例法因此**系统性高估热门的真实概率**——把热门赔率抬得过高，使「买热门」凭空产生虚正 ROI。

### 2.2 幂法（devig_power）才是 SSoT

项目 SSoT `pipeline/odds_math.py` 的 `devig_power` 在 docstring 中明确写道：**「比比例法更抑 FLB」**。所有涉及赔率的度量，一律走幂法，并做多方法敏感性测试。

### 2.3 事故的代价

2026-09-23 我们复现了一桩度量事故：

| 口径 | KNN 表观 ROI | 机械买热门 ROI | 配对差 |
|---|---|---|---|
| 比例法 (devig_n) | +5.86% | +5.15% | +0.71pp（CI 含 0） |
| 幂法 (devig_power) | +2.37%（CI 含 0） | +0.87% | +1.50pp（CI 含 0） |

比例法对热门赔率的虚高幅度平均 **+4.20%**。一个去水方法的选择，能凭空「造出」约 4% 的 ROI。**这 4% 就是幻觉。**

## 3. G6 零信息机械对照：区分真能力与吃偏差

这是我们的核心发明，也是旧五道关的「补天石」。

### 3.1 旧五道关为什么拦不住伪 edge

| 关卡 | 判据 | 被「买热门」钻空的理由 |
|---|---|---|
| G1 样本量 | n ≥ 2500 | 纯数量，热门策略同样达标 |
| G2 ROI CI | CI 下限 > 0 | 偏差本身就把下限顶成正的 |
| G3 质量 | LL<0 或 acc>1/3 | 无概率模型退化成 acc>1/3，买热门天然 >1/3 |
| G4 校准 | ECE/slope | 无概率 → 全 None → 「缺字段视为未违反」 |
| G5 方向二项 | p<0.05 | 同样由热门倾向驱动 |

**结论：五道关对「无概率的方向型模型」形同虚设。**

### 3.2 G6 怎么做

对每场计算「无脑买最短去水赔率（热门）」的纸盘收益，与模型实际 payoff 做**同场配对差**，判据是配对差的 bootstrap 95% CI **下限 > 0**。

> EDGE 需 G1–G6 全过；**G6 不过 → 直接 NO EDGE**（而非降级 INCONCLUSIVE）。

决定性证据：KNN 相对「什么都不做只买热门」的配对差为 +0.71pp，CI[-3.59%, +4.97%] **含 0**——即 KNN 没有任何可分辨的超额。KNN 的「EDGE」判定因此被**翻转**为 NO EDGE。

### 3.3 方法论金句

> **正 ROI 不是 edge 的证据，只是待解释的现象。**
> 任何盈利声称必须先过「零信息机械对照」：不用模型的最笨规则，在同一批比赛里能赚多少？

## 4. 诚实纪律（不可 override）

- 不伪造信号；不把未过六道关的模型当 edge 喊单；宁 PASS 不编造。
- 输出只解释概率偏差，**不喊单**（产品层已去喊单化）。
- 「edge / 稳胆 / 必赢 / 跟单」一律视为伪造，系统定位固定为「辅助诊断透镜」。
- 直播中比赛，用户的实时比分是地面真相，网络查证只作辅证，绝不覆盖。
- 任何 ROI 声称必带：胜率 / 隐含概率 / edge_pp / 零信息机械对照。

## 7. 给接手者的三个提醒

1. **别信账本里的旧 ROI。** 8824 行账本仍是比例法口径；新行起用幂法。跨口径不可混用判定。
2. **别被「INCONCLUSIVE」安慰。** 样本不足的 INCONCLUSIVE 不是 edge，是「还没证伪」；样本够的 NO EDGE 才是结论。
3. **先看纪律文件，再看代码。** 一切以 `docs/DISCIPLINE.md` 为唯一权威源（SSoT），旧 IR-xx 编号已全部废止。
