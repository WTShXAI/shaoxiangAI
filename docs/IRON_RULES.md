## 一、数据 / 单一真相源（SSoT）

### IR-01 盘口线 SSoT（2026-08-05 根治）
主盘线唯一来源 `opening_line.build_opening_lines()`（抽水最低线）。OU/AH 训练回测必须走 `clean_outcomes.load_clean_outcomes()` + `build_opening_lines()`，**禁直读 `match_outcomes` 盘口列**。

### IR-02 CS 波胆格式铁律（2026-08-17）
比分统一英文冒号 `0:0`（`normalize_cs_score` 唯一入口）；CS 赔率仅赛前（scheduled）采集，开赛后停采；写入须 normalize + 赔率 `(0,1000]` 边界。

### IR-03 CS 波胆 = 庄家资金引导器（非诚实锚）
最便宜波胆命中率仅 9.4%（诱导层）；真实 91.2% 真实比分被开出（2026-08-18 全量重验）。OU 是诚实锚，CS 是诱导层。抓跨庄价差需 `leyu_value_signal`（M4 点亮）。校准器 `models/cs_favorite_isotonic.joblib`。

### IR-04 分析口径三件套（2026-08-20，最高优先）
废止"OU 方向无稳定 edge / 只做对照不做决策"概括性铁律。废止"单庄必无 edge"前提。
**新口径**：OU/半场方向信号须逐场复盘三件套——① 开盘去水 P（大/小覆盖概率）② 开盘→临场漂移 ③ 联赛方差提示；**齐备才能下"庄家定小/定大"结论**。

### IR-05 GQ token 铁律
token = 乐鱼登录 URL 中 `token=` 后十六进制串 = requestid（前 18 位当 CUID）。换号写 `gq/.env` 的 `GQ_REQUEST_ID`，采集器 30s 热重载，无需重启。`0401038` 是误报（未开赛无赔率 ≠ token 死）。

## 二、实时状态机 / In-play 数据同步（⚡ 新增，来自 1-4/105' 诊断）

### IR-06 比分/时间状态机单调性（**新增 P0**，2026-08-24 诊断根因一）
**状态只进不退**：scheduled → live → half-time → finished，禁止任何回退。
- 终场判定须以实际结束事件为准（裁判吹终场 / 90+ 补时耗尽），**不得仅凭分钟数 ≥ 90 判定结束**。
- "上半场 105'"、"已结束 @ 120' 但实际 87 分钟" 这类矛盾属于**状态机硬错误**，必须在 bridge 层拦截——bridge 返回前端前校验 `minute` 与 `half` 字段的一致性（minute > 45 时 half 不可为 true；minute < 90 时 status 不可为 finished）。
- 比分下降（VAR 取消进球）须两帧确认防抖动。
- **前端卡片必须展示「最后更新时间」/数据新鲜度指示**，让用户判断数据是否陈旧。

### IR-07 In-play λ 动态刷新（**新增 P0**，2026-08-24 诊断根因二）
**模型输入必须随比赛事件（进球）实时刷新，禁用赛前静态 λ 在比赛中继续输出。**
- Poisson λ（期望进球）是波胆/1X2/OU 的共同数学根基。当客队已进 4 球但客队 λ 仍为赛前静态值 0.37 时，整个概率矩阵系统性失真（客胜仅 5.6%，与事实 1-4 完全背离）。
- 每次 collector 写入新 in-play 快照后，bridge 推断须用**当前比分 + 剩余时间**作为条件重新估计 λ(t)，而非固守赛前先验。
- 贝叶斯条件化更新：已发生的比分必须是 λ 后验的条件，不是简单的"全场 λ 减去已进球数"。
- **λ 与比分一致性告警**：当某队已进 ≥3 球但该队 λ < 0.5 时，须触发告警（λ 与事实严重背离），该场比赛的概率输出标记为"不可信"，不进入硬判定。

### IR-08 逆转/反转信号须以当前比分为先验条件（**新增 P1**，2026-08-24 诊断第四章）
逆转信号（如"逆转 63%"）、热门反转（Favorite-Longshot 反转）、平赔方向等模块，**必须以当前比分 + 剩余时间为贝叶斯先验做条件化压制**。
- 在 87 分钟 1-4 状态下，任何"主队逆转/反转"信号应被当前比分大幅压制（经验上 <10%）。
- 若逆转模块未接入当前比分这一最强特征，其输出在比赛后期将**系统性失真**，不可进入硬判定。

## 四、EV / Edge / 价值层（⚡ 新增/修订，来自诊断第三章）

### IR-17 EV/Edge 口径统一铁律（**新增 P1**，2026-08-24 诊断修复要点 D）
EV 与 edge 必须基于**同一概率、同一盘口**计算，口径不自洽则输出无效：
- edge = $P_{model} - P_{market}$（模型概率减市场隐含概率）
- EV = $(P_{model} \times Odds - 1)$ 或 $(P_{win} \times Profit) - (P_{lose} \times Stake)$
- **margin 剔除公式必须正确**：$m = 1 - 1/\sum(1/D_i)$，再用 $P_i = (1-m)/D_i$ 得到归一化隐含概率。对高 margin（>10%）尤其如此，简单 overround 近似会引入显著误差。
- 若出现"全方向 EV 负 + edge 正 + PASS"这种不自洽组合，**整条价值层输出标记为可疑，不进入硬判定**。

### IR-18 单庄 + 高 Margin 下价值层打折（**新增 P1**，2026-08-24 诊断根因五）
乐鱼单庄（单一数据源）+ margin > 15%（主流联赛 3-5%，低级别/单庄可更高）+ 低流动性三重条件下：
- 尖庄共识（SHARP_CONSENSUS_PROVIDER）信号稀疏，易被单一庄家盘口主导。
- **edge 信号仅作参考，不进入硬判定 PASS/FAIL**。
- 不据此单独做出"全方向负 EV 不接盘"的 PASS 结论——PASS 须有额外条件（如对冲/组合 EV）并在代码注释中明确。

### IR-19 低级别联赛校准可追溯（**新增 P2**，2026-08-24 诊断修复要点 F）
校准层的断言（如"隐含平局 21% vs 实际 ~16%"）**必须附带可回溯原始数据**：
- 联赛名、赛季、样本场数、先验分布参数、校准曲线（reliability diagram）。
- 缺少可追溯数据的校准断言**仅作参考，不进入硬判定**。
- 样本少的低级别联赛强制贝叶斯正则化（向先验均值 1.0 收缩，min 6 / max 14 场样本窗），避免极端 λ。
- 优化目标从准确率转向**校准/Brier score**（博彩场景下校准优于准确率更能产生收益）。

## 五、分析 / 研判 / 操盘

### IR-20 "分析非预测"措辞铁律
禁用"预测/必赢/稳胆"等确定性词，只做赔率结构解读。

### IR-21 建仓审批铁律
建仓必经 `/api/execute/confirm` 人工审批，AI 不伪造信号、不自动下注。

### IR-22 区分机构陷阱（2026-07-10）
多档盘口结构 → 陷阱在"最顺人性的线"；1X2 极低赔 = 免费局（非陷阱）；低水方向 = 庄家在护的"聪明边"。

### IR-23 单张 live 截图低水铁律（2026-07-10）
无开盘价时，"低水 = 庄家护的聪明边"是优先铁律 → 把低水线当"庄家真实预期"跟随，**绝不可反向把低水线说成'陷阱诱多'**。真陷阱判定必须有开盘→收盘漂移证据。

### IR-24 直播比赛闭环铁律（2026-07-10）
直播中的比赛，**用户的实时比分是地面真相**，网络查证只能作辅证，绝不覆盖用户实时反馈。

### IR-25 obscure 联赛领先后收缩防守假设不可靠（已两次证伪）
低级别联赛体能/战术纪律差，领先方未必守得住。单张深盘 live 不可据此判"不进球/不追平"。

### IR-26 操盘手三段框架
初盘立锚 → 临场 1h 平衡筹码 → 滚球动态调。核心 = 平衡账本 + 锁抽水（overround）。
