3. 数据污染证据 (决定性)

  • 49% 是单进球比赛: 275 场里 140 场总进球=1(0-1 或 1-0)。真实全场足球单球比赛约 20-25%。
  • 0-1 多于 1-0: 0-1=72 场 > 1-0=68 场 — 违反主场优势, 真实足球 1-0 应多于 0-1。
  • 8 场 minute=45 被标 finished(全322集): 半场就被当终场入库。
  • matches vs match_outcomes 303/307 一致(98.7%): 只证两表同源自洽, 不证真终场 — 共用同一乐鱼直播流, 共享同一 stale bug。

诊断: 进第一个球后乐鱼把该场从直播列表删除 → 采集器把当时比分(多为 1-0/0-1)冻结成"终场"。故实际比分是中途截断值, 那个 +1.22 的"总进球高估"是截断假象, 不是真高估。

4. 为什么坚决不动 goal_scale

  • gs=1.2(联赛)/1.35(WC) 源自 interwetten_odds 14万条庄家已结算真赛果 walkforward — 可信地面真相。
  • 322 场存疑乐鱼抓取 << 14万条结算结果的证据力。
  • 据脏数据把 gs 降到 1.0 → 生产模型对真实联赛系统性少报进球 → 直接有害。

5. 真正的抓手 (P1, 已修正)

  • 给 GQ 采集器加外部地面真相赛果校验: The Odds API scores 端点 / flashscore 式终场比分。
  • status='finished' 的写入条件收紧: minute≥90 且 比分跨多次抓取稳定 才落终场。
  • 在采集器修好之前: GQ 复盘只可做市场行为分析(CS初盘命中率、临场 drift), 禁用于模型 λ 校准。
铁律遵从: 输入仅赔率+实际比分, 零叙事。本次额外教训 — "只看数据"必须包含"验数据本身"; 两个内部表一致 ≠ 地面真相。
